# 맞춤형 학습지 생성기 (v8)

교과서 PDF를 올리면 AI가 교과서의 개념·문제·그림을 그대로 살린 학습지를 만들고,
**학생용 / 교사용(정답·풀이·지도 코멘트) HWPX(한글 문서)** 로 내려받을 수 있습니다.

## v8에서 바뀐 점
- **구성 = 역할 + 이름**: 활동마다 "역할"이 보이고 바꿀 수 있습니다. 역할은 수학 교과서 흐름을 따른 8가지입니다
  (도입 → 개념 도입 예시 → 개념 정리 → 확인하기 → 예제 → 풀이 전략 → 문제·유제 → 생각해보기).
  이름은 학습지에 찍히는 글자일 뿐이라, 이름을 바꿔도 AI가 넣는 내용은 역할대로입니다.
  (v7까지는 역할이 화면에 보이지 않아, 이름만 바꾸면 "문제" 역할에 "핵심 개념"이라는 이름이 붙는 식으로 어긋났습니다.)
- **구성 분석 개선**: 단원명·주제명("수열의 수렴", "정적분의 활용")을 활동 이름으로 읽지 않습니다. 이름표 없이 시작하는
  예시·개념 부분은 역할만 정하고, 판단 근거를 각 줄 아래에 보여 줍니다. v7 이하에 저장된 구성은 기본 흐름으로 바꿔 불러옵니다.
- **생성 지시 개선**: 교과서의 각 요소를 성격에 맞는 역할 하나에만 넣도록 했습니다(도입 문항을 개념 정리에 넣거나,
  개념 설명용 예시를 문제로 만들지 않음). 교과서의 채워 볼 표는 표로 옮기고, 빈칸은 핵심 용어·값에만 둡니다.
- **설정 정리**: "개념 설명(자세히/보통/간단히)"과 "빈칸 양"은 없앴습니다. 개념 설명의 양은 구성의 "개념 도입 예시"를
  켜고 끄는 것으로, 확인하기·예제·문제의 양은 구성 각 줄의 "문항 전부/대표 문항만"으로 정합니다.
- 이어지는 쪽 섹션 제목의 "(계속)"을 없앴습니다. 풀이 칸이 없는 쪽은 남는 공간을 한 칸에 몰지 않고 고르게 나눕니다.

## v7에서 바뀐 점
- **단원 전체를 안정적으로**: 먼저 축소 이미지로 "차시 계획"을 세운 뒤(가벼운 요청 1번) 차시마다 따로 만듭니다.
  - 끝난 차시는 바로 화면에 나타나고 브라우저에 저장됩니다. 오류가 나도 끝난 차시는 그대로 남습니다.
  - [이어서 만들기]는 남은(또는 실패한) 차시만 만듭니다. 차시마다 [↻ 다시]도 있습니다.
  - 새로고침하거나 창을 닫았다가 같은 교과서 PDF를 다시 올려도 이어서 만들 수 있습니다.
- **오류 이유 설명**: 503(서버 바쁨), 429(분당·하루 한도), 키 오류, 출력 길이 초과, Gemini의 RECITATION(교과서 문장 반복 차단),
  네트워크 끊김 등을 종류별로 구분해 이유와 해결 방법을 보여 줍니다. "자세히"에서 원문 메시지도 볼 수 있습니다.
- **자동 복구**: 서버가 바쁘면 10초·25초·50초 간격으로 다시 시도하고, 계속 바쁘면 같은 회사의 다른 모델로 전환합니다(끌 수 있음).
  RECITATION이면 설명을 학습지 문체로 바꿔 쓰게 해서, 출력이 잘리면 더 간결하게 해서 한 번 더 요청합니다.
- **연산 줄이기**: AI 생각 깊이(빠르게/보통/깊게), 이미지 해상도(교과서 높음·지도서 보통·차시 계획 낮음)를 나눠 씁니다.
  화면에 예상 요청 수와 실제 사용 토큰을 보여 줍니다. 검산을 끄면 요청 수가 절반입니다.
- **교사용 교과서·지도서(선택)**: 지도 TIP·지도 방향·유의점은 교사용에만 작은 코멘트 상자로 넣습니다.
  고등학교 범위를 넘는 "참고" 내용은 "심화 참고(교육과정 밖)"로 교사용에만 넣습니다.
  지도서 내용으로 "생각해보기" 질문을 만들고, 인쇄된 정답으로 정답을 확인합니다.
- **교사용 글씨 자동 조절**: 학생용과 교사용은 쪽마다 같은 표(블록)를 담고, 높이는 각자 맞춥니다.
  교사용 글이 많아 쪽을 넘치면 해설·지도 코멘트만 93%→86%→78%로 줄입니다.
- "개념 정리(네모 빈칸) · 개념 정리(네모 빈칸)"처럼 제목이 겹치던 문제를 고쳤습니다(괄호 설명은 활동 특징으로만 씀).

## 이전 판의 기능
- 여러 AI 선택(Gemini·Claude·OpenAI·OpenAI 호환). API 키는 각자 브라우저에만 저장됩니다.
- 내 학습지 구성 분석·편집, 기출문제·수능특강 교사 작성 쪽, 레이아웃 5종 + 레이아웃 참고 파일 분석.
- 한 차시 = A4 정확히 2쪽, 표가 쪽을 넘지 않게 맞춤, 한글 수식 편집 지침 반영.
- 교과서 그림 잘라 넣기([✂ 위치 조정] / [+ 그림]), 정답 검산, AI 수정 요청, 내용 직접 고치기.

## 배포 (Vercel 무료)
1. 이 폴더의 **내용물**을 GitHub 저장소에 올립니다(기존 파일 덮어쓰기).
2. vercel.com이 자동으로 다시 배포합니다. 환경변수는 필요 없습니다.

## 로컬 실행
npm install && npm run dev → http://localhost:3000

## 구조
- `app/page.js` 입력·진행 화면 / `app/api/proxy/route.js` (선택) 서버 경유 연결
- `components/JobPanel.js` 진행 상황·오류 설명 / `ModelView.js` 미리보기 / `CompositionEditor.js` / `LayoutPicker.js` / `CropEditor.js`
- `lib/job.js` 차시 계획 → 차시별 작성 → 합치기 / `lib/errors.js` 오류 분류·설명 / `lib/llm.js` AI 호출(재시도·모델 전환)
- `lib/content.js` 만들기 설정(생각 깊이 등) / `lib/composition.js` 구성 / `lib/layouts.js` 레이아웃 / `lib/themes.js` 색
- `lib/compose.js` 학습지 → 표 / `lib/measure.js` 높이 계산 / `lib/paginate.js` 2쪽 맞춤
- `lib/hwpx.js` HWPX 생성 / `lib/latex2hwp.js` LaTeX → 한글 수식 / `lib/eqMeasure.js` 수식 크기
- `lib/prompt.js` 지시문 / `lib/jsonRepair.js` 응답 복구 / `lib/doc.js` 데이터 정리 / `lib/rich.js` 수식·빈칸 표기
- `lib/pdfClient.js` PDF → 이미지 / `lib/figures.js` 그림 잘라내기 / `lib/sample.js` 샘플
